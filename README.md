# Huffman_Coding
Huffman Encoding of .txt files using Java language. 
A new file of the same text encoded by the provided codes will be made in the same folder as the original file.
No damage will be caused to the original file
Have all the codes in the same folder and then run the main method. 
If the .txt file is in the same folder, the name of it is enough. 
If not, write the full name, including the path.
